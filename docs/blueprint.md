# **App Name**: VS Imports Brasil

## Core Features:

- Catálogo de Produtos: Exibir um catálogo de produtos importados, imitando o estilo do site fornecido. Os produtos incluem imagem, nome, descrição e preço.
- Carrinho de Compras: Permitir que os usuários adicionem itens exibidos a um carrinho de compras virtual.
- Checkout via WhatsApp: Um botão 'Finalizar Compra' envia os itens do carrinho como uma mensagem formatada para um número de WhatsApp especificado.
- Design Responsivo: Garantir que o site se adapte e seja exibido corretamente em vários tamanhos de tela, incluindo dispositivos móveis.

## Style Guidelines:

- Cores primárias: tons de verde e roxo, implementados usando Tailwind CSS.
- Cor de destaque: rosa brilhante para destacar elementos interativos e botões de chamada para ação.
- Manter um layout semelhante ao site fornecido para uma experiência de usuário familiar.
- Use ícones claros e reconhecíveis para navegação e ações como 'Adicionar ao Carrinho' e 'Finalizar Compra'.
